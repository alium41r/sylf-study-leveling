# Sylf Notes Phase 4 implementation report

**20 October 2026.** The paper-notebook implementation is delivered locally. Automated and browser qualification passed within the scopes below. **Public-release qualification remains open**, especially physical stylus behavior, live Google/deployment acceptance and sustained long-history synchronization. Phase 5 and the separate Study Workspace were not started.

Current behavior is defined in the [paper/handwriting contract](../../ink.md), extending the existing [foundation](../../foundation.md) and [workspace/Drive contract](../../workspace.md). The Phase 0–3 contracts/reports, Phase 3 handoff and complete [Workspace master plan](../../../workspaces/master-plan-october-2026.md) were reviewed; the document/session/workspace ownership boundaries remain intact.

## Delivered

- Handwritten notebooks alongside existing rich-text notes: pressure-sensitive pen, translucent highlighter, whole-stroke eraser, lasso selection, move, uniform resize, recolor/rewidth, undo/redo and keyboard editing. Authored colors remain independent of Sylf appearance.
- Imperative native/coalesced pointer input and Canvas 2D rendering, with no React update for every sample. Pen pressure, elapsed time, available tilt/twist and original vectors are retained. Mouse and optional finger writing coexist with touch pan/pinch, pointer-centered zoom, Fit width, pen priority and palm heuristics.
- Blank, ruled, grid and dotted paper with custom paper/rule colors; independent pages, visible thumbnails, previous/next, add, duplicate, reorder, retained Removed pages, restore and focus writing. The existing responsive library drawer and semantic theme tokens are reused.
- Existing encrypted local autosave, durable outbox, portable archives, history previews/restoration, explicit failure/retry and emergency export. Input is captured at flush/pause/closure boundaries; cancelled pointers retain observed ink. A failed save disables further writing and never receives a saved acknowledgement.
- Stable page/document references and Notes-owned viewport resumption for future consumers. No scratchpad, whiteboard, timer, session or Workspace authority was duplicated. No note/preview bodies enter Supabase/Prisma.

## Decisions and implementation

| Decision                                                          | Reason and consequence                                                                                                                                                                                                                                                                                                                 |
| ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pin **Perfect Freehand 1.2.3**, MIT, with Canvas 2D.              | Uses the Phase 1 preferred geometry foundation without a paid canvas dependency. Existing editor/Yjs/Dexie pins remain. Generated notices now cover 57 packages; the 690-file BlockNote covered-source ZIP is byte-exact and unchanged. See [license proof](evidence/license-source-verification.json).                                |
| Add `sylf-ink/1` inside envelope v1 / normal Yjs 13 page streams. | Original samples, chunks, explicit stroke endings, edits and authored paper are merge authority. Geometry/bitmaps are derived. Old clients must reject the required `ink-v1` feature; they cannot approximate/reseed it. Page copies retain native vectors in new page/stream identities.                                              |
| Keep one repository, stream engine and synchronizer.              | No migration or new provider grant is required. New input-boundary hooks capture observed work before existing flush/revocation. All transactional, account fencing and cloud readback rules remain.                                                                                                                                   |
| Cache validated native state by exact committed frontier.         | Private Y.Doc ownership is consumed before mutation and advanced only after commit; abort/conflict/revocation destroys tentative state. Checkpoint/causal validation remains. A rollback-poisoning regression test prevents rejected updates entering the next validator. This avoids full dense-page re-encoding for every warm save. |
| Bound derived rendering and hydrate pages independently.          | Two viewport canvases, page raster, path LRU/spatial culling, serialized visible thumbnails and released offscreen caches. The encoded verifier cache estimate is not a measured heap bound. Cold replay and large selection operations remain more costly.                                                                            |
| Permit bounded multi-batch foreground publication.                | Up to five batches of 100 revisions, yielding and checking a five-second budget **between** batches. An individual batch is not preempted. Pending jobs remain durable; no pruning or false cloud-save status hides a backlog.                                                                                                         |
| Preserve removed pages and reject unresolved metadata branches.   | Last active page removal is blocked; restore is explicit. Opening/adding pages cannot silently choose one unresolved descriptor branch. History restore creates a separate copy.                                                                                                                                                       |

Concurrent independent strokes survive. Deterministic edit ordering composes transformations; explicit later style/erase fields determine the visible projection while native operations remain retained. Local undo is origin-scoped and cannot remove another producer's independent stroke. This is defined merge behavior, not a promise of simultaneous geometric intent resolution.

Open streams also skip unchanged-frontier replay on upload receipts and polling. Actual remote frontiers retain validated replay and the local-activity guard. The existing late-replay regression now introduces a real remote revision before delaying adoption, preserving its race coverage rather than depending on unnecessary replay.

## Measured performance

Final isolated headless Chromium desktop run, with builds/tests finished; **5,000 strokes / 320,000 original samples**, native state 14,335,514 bytes. These are production-module measurements, not physical pen-to-display or live provider latency. [Exact results](evidence/ink-performance-results.json), [reproduction](../../../../scripts/qa/notes-ink/README.md).

| Measurement                                                     |                 Median | 95th percentile / other result |
| --------------------------------------------------------------- | ---------------------: | -----------------------------: |
| Dense-page pan (20 samples)                                     |                 1.7 ms |                         3.2 ms |
| Active 64-sample path rendering (100 samples)                   | below timer resolution |             0.1 ms; max 0.8 ms |
| Active 4,096-sample path rendering (100 samples)                |                 0.7 ms |             1.4 ms; max 2.0 ms |
| Warm encrypted native save (20 saves)                           |                 3.8 ms |                        12.9 ms |
| Saves after metadata change (10 saves)                          |                 3.7 ms |                         4.2 ms |
| Open/release among 300 **empty** page streams (12 measurements) |                10.3 ms |                        13.2 ms |
| Cold native hydration / cold render                             |                      — |            920.7 ms / 224.9 ms |

Fixture construction took 1,489.5 ms. After the dense seed and 30 small subsequent edits, encrypted object bytes were 14,388,360 across 73 objects / 34 retained revisions; the dense page was not rewritten for every small edit. This is a warm-save/storage result, not a long-history benchmark. The renderer retained 384 paths / 24,576 cached points, a 1,572,864-pixel viewport backing and a 3,520,000-pixel page raster. Total process/GPU memory was not measured. An [earlier navigation run](evidence/performance-earlier-observation.json) showed a **304.5 ms tail**; the final quiet result does not remove cold/load/device variability.

Working desktop budgets were under 8 ms for ordinary active-path rendering, under one 16.7 ms frame for warm dense-page pan, and under 20 ms for warm small local saves. The final fixture meets these budgets. Cold hydration exceeds a frame and must remain a visible loading boundary. These budgets do not qualify every supported page limit, device, mass-selection redraw or end-to-end interaction.

## Unresolved risks and release gates

1. **Long-session cloud throughput is not qualified.** The 310-revision bounded-pass queue test passes and retains all 310 strokes/source revisions; the final regression asserts receipts cause no unchanged source-page replay. Its isolated run took 19.46 seconds; the final full-suite run took 22.94 seconds for this case. An earlier attempt exceeded 60 seconds under concurrent checks; [pre-fix diagnostic evidence is retained](evidence/long-history-stress.log). The specific receipt-notification replay cost was fixed. Remaining ancestor/discovery/audit costs still need minutes/hours of real writing and interrupted/offline catch-up profiling before broad release. Preserve original history and verified coverage in further optimization. This synthetic queue result does **not** establish real-provider throughput or unlimited histories.
2. **Physical devices remain unqualified.** No Apple Pencil, S Pen, Safari/iPad, Android WebView or native input test was available. Coalesced event support, barrel buttons, touch heuristics and sampling differ. Synthetic pen events cannot establish natural writing quality or OS palm rejection. Test fast/slow/light/heavy writing, sustained pages, zoom/palm gestures, interruptions, thermal load and memory on target tablets before promising parity with specialist apps.
3. **Live Google/deployment gates remain.** Notes origin/key configuration and an authorized test grant were unavailable. Existing general Google credentials are not a test grant. No live consent, production CORS/cookies, hosted migration or deployed readback was tested. Follow the [Phase 3 setup/live checklist](../phase-3/setup.md); keep server credentials out of shared/mobile code and review native authentication separately.
4. **Browser durability is bounded.** Loaded unlocked sessions can edit offline; cold offline reopening stays locked. Explicit clearing/eviction/device loss can destroy unsynchronized local data. Process termination can lose unacknowledged in-memory samples. Browser saves are not a guarantee against power failure. Back up both server encryption and wrapped vault keys; provider-readable cloud/export v1 is **not E2EE**.
5. **Finite scope/limits remain visible.** Erasing removes whole strokes; no partial/pixel eraser, pressure-calibrated native brush engine, OCR or handwriting search. Paths continue at about 4,096 samples with separate continuation undo groups. Current-state caps (500,000 samples / 10,000 strokes / 60,000 operations per page) are safety limits, not performance promises. Long native/undo histories, cold replay, dense selection, independent backups and archive/export limits still require scale/device work. Nothing silently expires source history.

## Phase 5 readiness and approval boundary

The new ink adapter, native sample format, page lifecycle, rendering/controller boundary, references and recovery hooks are available for the next separately approved phase. Future PDF annotations, scratchpads and whiteboards should reuse them and the canonical Notes repository; Workspaces reference documents and canonical sessions without taking ownership.

No new paid dependency, schema migration or additional provider permission needs approval for this local implementation. **Public rollout should wait for the gates above.** Retain the existing online cold-unlock, provider-readable cloud and key-backup policies unless explicitly revisited. A native protected-storage/input adapter may need to move earlier if tablet qualification fails. Any change to encryption, history retention/compaction, cross-account migration or background/native capability requires its own reviewed contract.

Phase 5 feature selection and the separate Workspace implementation remain unstarted and require separate authorization. Detailed source hashes, logs and reproduction links are in the [evidence index](evidence/README.md).
