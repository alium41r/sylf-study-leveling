## Changes

- New `student-preview-v2` admission uses LOW for Research/verification/OCR and
  translation; natural strategy and independent review remain HIGH. All token,
  context, root, holdback, spending and deadline allowances remain unchanged.
  Legacy v1 admission and already admitted policies retain their exact meaning.
  LOW is intentional: DeepSeek maps MEDIUM to HIGH in its
  [official effort contract](https://api-docs.deepseek.com/guides/thinking_mode/).
- New Research captures pin a focused protocol: gather factual context, close
  material gaps and hand off promptly. They must not design lessons, schedule,
  solve the papers or exhaustively catalogue resources. Other roles now have
  explicit task boundaries in their existing retained instructions.
- Action packets carry the schema-derived contract. A single settled invalid
  response correction receives safe exact validator paths/types/field bounds.
  Raw receipts stay immutable; evidence anchors are never invented or accepted
  when missing. Tool results retain explicit read/discovery/empty/failure status.
- The existing workspace endpoint now exposes a read-only SSE view of existing
  fenced display payloads. The client consumes frames immediately; roughly
  350 ms write coalescing and 400 ms lightweight reads replace multi-second full
  snapshot polling for live text. Full chronology refreshes on checkpoint changes.
  Active reasoning opens automatically. No synthetic typing or narration calls.
- Ownership/plan/root/fence checks, safe display redaction, finite connections,
  logout rejection, cancellation, truthful accounting, immutable history,
  compiler-v1 interpretation and atomic Apply remain intact. There is no new
  provider route, event table, agent process or execution lifecycle.

The initial full regression run retained 648 passes and one failing streaming
regression. Investigation on 1 November found a genuine SQL defect in the new
live projection: the same parameter was compared with a UUID column and a JSON
text reference without explicit casts. The projection now casts each comparison
to its actual type. The regression still requires two incremental previews
before response completion and settlement; no timing allowance was increased.
Its foreign-plan assertion now expects the existing `PLAN_NOT_FOUND` privacy
response from the first ownership guard, rather than the later guard's error.
The original failing receipts remain in `evidence/final-postgres/`.
