# Phase 1 execution writer dispositions

All 36 frozen Phase 0 behavior groups have a disposition. This is paired with [machine-readable ownership](writer-dispositions.json), [the original exact-site/RPC inventory](../2026-10-02-phase-0/execution-writers.json), and the final [gate report](README.md).

The common authority is transaction-scoped advisory namespace **73641**, user first, then sorted Plan/Attempt, Session, Quest, and economic rows. ORM mutations use `executionTransaction`; raw durable services use `PlannerDatabase.coordinated`. Effective RPCs acquire the same user lock before their existing economic locks. Providers run outside these transactions. PostgreSQL source/execution guards reject uncoordinated consequential writes for adopted users. Cosmetics and independent social-party state are intentionally outside educational currentness.

## SQL and indirect writers

The new migration replaces effective start/settle/complete/Quest-claim, shop/equipment, skill/Apex and achievement boundaries without editing their historical migration files or reward formulas. Catalog tests verify effective signatures, ownership/membership, immutable artifacts, RLS/revocations and trigger behavior. Unused `commit_focus_progression(integer × 7)`, `commit_forge_progress(text, integer, integer)` and `unlock_skill_node(integer)` bypass signatures are dropped after source caller inspection. Current atomic APIs remain.

Generic linked edits do not detach or rewrite tasks. They return an explicit conflict/protocol requirement until a sealed change is available. Old Planner generation/materialization/stretch/reoffer/Copilot paths reject adopted Plans; unadopted legacy work remains bounded during expand/backfill. This is not a second engine for a V2 Goal. Turning off admission cannot restore legacy access to adopted work.

Goal, Subject, node, rest, User and economic/FK side effects are included in the SQL backstops. Account deletion is the authorized history-erasure exception; ordinary reset cannot erase linked execution. Completion and elapsed time are separate. Withdrawn originals cannot mint completion rewards, even when a continuation exists.

## Qualification limits

The harness tests repository-installed SQL and actual selected routes in an isolated PostgreSQL instance. It does not attest hosted function bodies, migration drift, external cron jobs, operator privileges or distributed app builds. Those remain explicit Phase 5 release checks. Independent Focus Party tests establish its separate authority; no new social timer engine or implied StudySession pause was introduced. Mobile mocks are not integrity evidence.
