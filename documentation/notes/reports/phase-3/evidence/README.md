# Phase 3 verification evidence

20 October 2026, macOS arm64, Node 24.19.0, existing bundled Playwright/Chromium. All cloud/accounts/documents in these runs were synthetic. No live Google test grant or hosted database migration was used. The current implementation/report lives [one level up](../report.md); [setup and unperformed live gates](../setup.md) are separate.

## Final acceptance artifacts

- [`final-checks.json`](final-checks.json): completed local checks and their recorded outcomes; all live/deployment limitations below still apply.

- [`regression.log`](regression.log): 171 passing tests across ten files. Production Notes foundations, encryption, source/portable recovery, transfer/packing, OAuth/broker mocks, auth/logout/account routes, appearance and immersive controls. Fake IndexedDB and fake network are explicitly part of unit coverage.
- [`browser-results.json`](browser-results.json), [`browser.log`](browser.log): 15 real Chromium scenario groups using the actual shared Notes screen, Sylf providers/shell, editor, encrypted IndexedDB repository and provider adapter. Tests use synthetic HTTP grants/Drive storage; provider acceptance is not simulated as a deployment success.
- [`accessibility-results.json`](accessibility-results.json), [`accessibility.log`](accessibility.log): actual coarse-pointer controls (44-pixel toolbar targets), first-field native-dialog focus/Escape, Recovery and existing account-deletion disclosure. Focused checks, not a full screen-reader/WCAG audit.
- [`performance-results.json`](performance-results.json), [`performance.log`](performance.log): actual encrypted repository with 1,000 synthetic empty documents, 50 initial card nodes, catalog timing and 50 small native saves. Not large-content/physical-mobile/provider-cost qualification.
- [`offline-results.json`](offline-results.json), [`offline.log`](offline.log): actual service worker cached only the public locked fallback; no authenticated route/API cache or offline cold content unlock.
- [`postgres.log`](postgres.log): actual additive Notes metadata migration and database constraints/security on a disposable PostgreSQL 17 minimal User baseline. No full historical migration rehearsal or deployed database access.
- [`typecheck.log`](typecheck.log), [`lint.log`](lint.log), [`shared-lint.log`](shared-lint.log): final root typecheck and targeted lint. Empty logs indicate successful no-output checks. Five warnings in Sidebar/mobile outlet also occur in their untouched staged baseline: [`shared-lint-baseline.json`](shared-lint-baseline.json).
- [`web-build.log`](web-build.log), [`mobile-build.log`](mobile-build.log), [`mobile-verify.log`](mobile-verify.log): final builds and client/server/secret-boundary audit. Native OAuth/CORS/IME/storage/hardware reliability is not established by compilation.
- [`notices.log`](notices.log), [`license-source-verification.json`](license-source-verification.json): installed dependency notices and exact BlockNote source ZIP validation. Licensing review/source offer is not a legal clearance or vulnerability audit.
- [`source-snapshot.json`](source-snapshot.json): hashes of the qualified source/docs. This is a current-scope snapshot, not an assertion that every listed Phase 2 file was created in Phase 3. [`baseline.json`](baseline.json) discloses its partial/intermediate capture limits.

Screenshots: onboarding; desktop editor; tablet light; phone custom light/dark surfaces; phone library/navigation; Recovery; account-deletion warning; locked offline fallback. These are browser viewport simulations, not hardware runs. Screenshots were inspected and visual issues repaired, including modal placement, keyboard focus and the fullscreen/Recovery control overlap.

## Reproduction

Use the [isolated harness instructions](../../../../../scripts/qa/notes-workspace/README.md) and existing dependencies. The drivers write into this directory and use disposable contexts. `test-notes-postgres.mjs` never reads a hosted URL and uses `--pull=never`. The current public source artifacts are generated by `scripts/build/build-notes-notices.mjs` and copied by normal web/mobile builds.

Logs/screenshots named `initial`, `foundation-regression`, `contracts`, `notes-tests`, `phase3-foundation-tests` or `browser-failure` are intermediate diagnostic runs. The acceptance artifacts above are authoritative for this phase's final run. Earlier phase evidence retains its own source/time/coverage scope.
